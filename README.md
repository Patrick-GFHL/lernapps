# Lern-Hub

Lern-Apps mit Sternen, XP und Erfolgen. Läuft über GitHub Pages: https://patrick-gfhl.github.io/lernapps/

Neue App: eigenen Ordner anlegen, in `index.html` (Liste `APPS`) eintragen und in `sw.js` (Liste `FILES`) ergänzen, Cache-Version hochzählen. Gemeinsames Profil (XP, Rang, Serie, alle Erfolge): `shared/profil.js` einbinden und `window.LernHub` nutzen.
